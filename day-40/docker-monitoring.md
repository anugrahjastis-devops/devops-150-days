# 📊 Day 40: Docker Inspect, Logs & Resource Monitoring

## 📌 Overview
Today I learned how to debug and monitor running containers using Docker's native diagnostic tools: `docker logs`, `docker inspect`, and `docker stats`.

---

## 💻 Commands Implemented
1. `docker logs pulled-web-container` - Checked live standard output and error logs of the running container.
2. `docker inspect pulled-web-container` - Extracted deep low-level configurations, network settings, and JSON metadata.
3. `docker stats` - Monitored real-time CPU usage, memory consumption, and network I/O across active containers.
