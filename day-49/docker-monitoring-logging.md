# 📊 Day 49: Docker Monitoring, Resource Stats & Logging

## 📌 Overview
Today I learned how to monitor container resource health in real-time and inspect container logs for application troubleshooting and debugging in production environments.

## 💻 Implementation
1. Monitored live container resource consumption using `docker stats`.
2. Inspected standard output logs of production containers using `docker logs resilient-container` to verify startup sequences, worker process states, and runtime health.
