# Day 61: Advanced Triggers, Environment Variables & Encrypted Secrets

## Key Concepts Covered
- **Advanced Triggers:** Branch filters (`branches: [main]`), path filters (`day-61/**`), and manual triggers (`workflow_dispatch`).
- **Environment Variables (`env`):** Defining workflow-level and step-level variables.
- **Encrypted Secrets (`secrets`):** Storing sensitive values in GitHub repository settings and referencing them securely via `${{ secrets.NAME }}`.
