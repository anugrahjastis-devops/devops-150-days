# 🐳 Day 51: Introduction to Docker Compose & Multi-Container Architecture

## 📌 Overview
Today I started learning Docker Compose, an orchestration tool used to define and run multi-container Docker applications using a single YAML file.

## 🚀 Key Learnings & Practical Implementation
1. **Declarative Infrastructure:** Created a `docker-compose.yml` file to manage multi-container application definitions in a single place.
2. **Single-Command Orchestration:** Deployed an Nginx web service container seamlessly using the `docker compose up -d` command.
3. **Automated Networking:** Observed how Docker Compose automatically provisions dedicated internal networks for container communication.
